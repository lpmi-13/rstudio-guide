# Statistical tools

Five base R tools for describing data: `min()` and `max()`, `mean()`,
`median()`, `quantile()` and `summary()`. The examples use the temperature
column of R's built-in `airquality` data.

Choose a mode in the Coach pane on the right: watch the coach type and run each
line (Demonstration), do it yourself with hints (Guided), or work through the
whole list on your own (Solo). Each line goes below its step heading in
`statistical-tools.R`. To run a line, put the cursor on it and press Ctrl+Enter,
or click **Run**.
