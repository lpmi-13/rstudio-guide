# Statistical tools

A demonstration of five base R tools for describing data: `min()` and
`max()`, `mean()`, `median()`, `quantile()` and `summary()`. The examples use
the temperature column of R's built-in `airquality` data.

The coach runs `statistical-tools.R` one line at a time. You can run any line
yourself: put the cursor on it and press Ctrl+Enter, or click **Run**.
